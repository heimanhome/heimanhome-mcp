# Heiman Smart Home Connector — Русский

**Пакет метаданных MCP-коннектора** для клиентов, совместимых с WorkBuddy / CodeBuddy. Позволяет ИИ-ассистенту запрашивать данные и управлять устройствами умного дома на естественном языке: освещение, кондиционеры, шторы, температура и влажность, журналы устройств, дома и комнаты, сценарии, возможности устройств, охрана, уведомления и информация о прошивке (только чтение).

> **Этот репозиторий содержит только метаданные коннектора, но не реализацию сервера.**
> Это сторонняя интеграция: **не официальный продукт Heiman, WorkBuddy или CodeBuddy**, без поддержки и сертификации со стороны любой из этих организаций. См. `OPEN-SOURCE-STATEMENT.md`.

**Язык:** английская версия является авторитетной. Этот перевод носит справочный характер; при расхождениях действует [`../README.md`](../README.md). Юридические тексты (`LICENSE`, `NOTICE`, `OPEN-SOURCE-STATEMENT.md`) авторитетны только на английском языке.

## Перед использованием

`https://smart-home-mcp.example.com/mcp` в `mcp.json` и `connector-meta.json` — это **заглушка-пример**. Установленный «как есть» пакет ни к чему не подключится. Необходимо:

1. Развернуть публично доступный по HTTPS MCP-сервер (Streamable HTTP + OAuth, RFC 9728 / 8414 / 7591 / 7636 / 7009) с 39 инструментами из `SKILL.md`.
2. Заменить `example.com` в обоих JSON на реальный адрес `https://<домен>/mcp`.
3. Подтвердить версию клиента, требуемую для `auth_mode: server-side` (`minWorkbuddyVersion: 4.24.0`).
4. Законно получить `clientId` / `clientSecret` и разрешение на интеграцию у исходной платформы; учётные данные должны храниться **только на сервере**.
5. Проверить оба файла: `python3 -m json.tool connector-meta.json` и `python3 -m json.tool mcp.json`.

Без разрешения на товарный знак: используйте нейтральное имя проекта и собственную иконку, обновив оба JSON, `SKILL.md` и все переводы.

## Scopes

Если scope не запрошен, сервер должен выдать только чтение (`device:read`, `scene:read`). Права на запись (`device:control`, `scene:execute`, `security:control`) пользователь должен явно отметить на странице согласия. Постановка/снятие с охраны и редактирование сценариев дополнительно требуют `confirm=true`; рискованные действия стоит предварительно проверить через `dry_run=true`.

## Локализованные тексты для маркетплейса (`ru`)

Источник: `connector-meta.json` → `i18n.locales.ru`.

- **Название:** Heiman Smart Home
- **Описание:** Управляйте устройствами умного дома Heiman и запрашивайте данные на естественном языке: свет, климат, шторы, температура, журналы, комнаты и сценарии.
- **Примеры:**
  1. Установите яркость света в гостиной на 50 %
  2. Какая сейчас температура и влажность в гостиной?
  3. Включите кондиционер в гостиной и установите 26 °C
  4. Закройте шторы и запустите сценарий «Дома»
  5. Покажите среднюю температуру и влажность за последние 24 часа
