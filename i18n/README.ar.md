# Heiman Smart Home MCP — دليل الاستخدام (العربية)

استعلم عن أجهزة المنزل الذكي وتحكّم بها باللغة الطبيعية عبر مساعد ذكاء اصطناعي: الإضاءة، التكييف، الستائر، الحرارة والرطوبة، سجلات الأجهزة، الغرف، المشاهد ونظام الإنذار.

| | |
| --- | --- |
| نقطة النهاية | `https://spmcp.heimanhome.com/mcp` |
| بروتوكول النقل | MCP Streamable HTTP |
| التفويض | OAuth 2.1 مع PKCE (تسجيل الدخول بحساب المنزل الذكي) |
| المستودع | `https://github.com/heimanhome/heimanhome-mcp.git` |
| الدعم | `help@heimanhome.com` |

> النسخة الإنجليزية [`../README.md`](../README.md) هي المرجع المعتمد، وهذه الترجمة للاسترشاد فقط. العربية تُكتب من اليمين إلى اليسار، بينما تبقى كتل الأكواد وأسماء الأدوات و`JSON` من اليسار إلى اليمين.

## 1. الاتصال والتفويض

1. أضف نقطة النهاية إلى عميل MCP بإحدى التهيئات أدناه.
2. يفتح العميل صفحة التفويض؛ سجّل الدخول بحساب المنزل الذكي.
3. راجع الصلاحيات: تُمنح صلاحية القراءة فقط افتراضيًا، ولا تُمكّن صلاحيات الكتابة إلا عند التحكم في الأجهزة.
4. أكّد التفويض. يحتفظ العميل بالرمز المميز، ولا تُحفظ بيانات الحساب في هذا المستودع.

## 2. تهيئة العميل

**`mcp.json` عام** (Claude Desktop وCursor وCline وWindsurf وZed وVS Code + GitHub Copilot وMCP Inspector):

```json
{
  "mcpServers": {
    "heiman-smart-home": {
      "type": "streamableHttp",
      "url": "https://spmcp.heimanhome.com/mcp",
      "timeout": 30000
    }
  }
}
```

**Claude Code**:

```bash
claude mcp add --transport http heiman-smart-home https://spmcp.heimanhome.com/mcp
```

**العملاء الذين يدعمون stdio فقط** — استخدم جسر `mcp-remote`:

```json
{
  "mcpServers": {
    "heiman-smart-home": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://spmcp.heimanhome.com/mcp"]
    }
  }
}
```

**العملاء المستضافون** (ChatGPT وClaude.ai وCopilot Studio وGemini CLI وWorkBuddy / CodeBuddy): سجّل خادم MCP بعيدًا من واجهة العميل باستخدام نقطة النهاية نفسها.

## 3. النطاقات وعمليات الكتابة

| النطاق | يسمح بـ |
| --- | --- |
| `device:read` | قوائم الأجهزة، الحالة، القدرات، البرنامج الثابت، السجلات، المستشعرات |
| `device:control` | التشغيل والإيقاف، السطوع، درجة الحرارة، الستائر |
| `scene:read` | المشاهد، الغرف، المنازل، الأتمتة |
| `scene:execute` | تنفيذ المشاهد والأتمتة وإنشاؤها وتعديلها وحذفها |
| `security:control` | التفعيل / الإلغاء، إقرار الإنذارات |

- عند عدم طلب نطاق صريح تُمنح صلاحية القراءة فقط.
- العمليات الحساسة تتطلب `confirm=true`، ويُنصح بمعاينتها أولًا عبر `dry_run=true`.
- عند إعادة المحاولة استخدم `idempotent_key` ثم استعلم بـ `get_command_status(trace_id)`؛ النجاح يعني أن الأمر **قُبل** لا أنه نُفّذ بالضرورة.
- `whoami` يعرض الهوية والنطاقات الممنوحة. عند الرفض، صحّح النطاق أو المعامل أو التأكيد بدل تكرار الطلب نفسه.

## 4. أمثلة على الطلبات

```
اضبط سطوع مصباح غرفة المعيشة على ٥٠٪
ما درجة الحرارة والرطوبة الحالية في غرفة المعيشة؟
شغّل مكيف غرفة المعيشة واضبطه على ٢٦ درجة
أغلق الستائر ثم شغّل مشهد «العودة إلى المنزل»
اعرض متوسط درجة الحرارة والرطوبة خلال آخر ٢٤ ساعة
```

يجيب المساعد بلغة المستخدم؛ أمثلة بثماني لغات في `connector-meta.json` → `i18n.locales`.

## 5. المشكلات الشائعة

| العَرَض | الحل |
| --- | --- |
| `401` / انتهاء التفويض | أعد الاتصال والتفويض من العميل |
| النطاق غير ممنوح | أعد التفويض واختر النطاق المطلوب |
| قُبل الأمر ولم يتغير الجهاز | استعلم بـ `get_command_status(trace_id)` وانتظر |
| طلبات كثيرة | انتظر قبل إعادة المحاولة ولا كرّر الطلب ذاته |
| تعذّر الاتصال | تأكد من دعم Streamable HTTP + OAuth وإتاحة نقطة النهاية عبر HTTPS |

## 6. الأمان والخصوصية

- أوامر التحكم تغيّر أجهزة حقيقية: راجع معاينة `dry_run` وقلّل صلاحيات الكتابة.
- تبقى الرموز المميزة وبيانات الدخول على الخادم. لا تنشر رموزًا أو كلمات مرور في المشكلات العامة؛ أبلغ عن الثغرات عبر `help@heimanhome.com`.
- مشغّل الخدمة البعيدة هو المتحكم في بيانات المنزل والأجهزة: راجع `OPEN-SOURCE-STATEMENT.md`.
